Firebase & Settings

Konfigurasi backend dan koneksi database

Status Koneksi
● Tidak terhubung
Cara Setup Firebase (Langkah demi Langkah)
1
Buat Firebase Project
Buka console.firebase.google.com → klik "Add Project" → beri nama (misal: zackyhilmi-portfolio) → Create Project.
2
Aktifkan Firestore Database
Di sidebar Firebase Console → Build → Firestore Database → Create Database → pilih Start in test mode → pilih region (misal asia-southeast1) → Enable.
3
Aktifkan Firebase Storage
Di sidebar Firebase Console → Build → Storage → Get Started → Start in test mode → Done. Storage digunakan untuk upload gambar project.
4
Aktifkan Authentication
Build → Authentication → Get Started → Sign-in method → Email/Password → Enable → Save. Lalu tambah user: Users tab → Add User → masukkan email & password kamu.
5
Ambil Firebase Config
Project Settings (ikon gear) → General → Your Apps → klik ikon Web (</>) → Register app → salin config object. Isi field-field di bawah.
Firebase Configuration

Config disimpan di localStorage browser kamu. Tidak dikirim ke server manapun.

Firestore Security Rules (salin ke Firebase Console)
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}
